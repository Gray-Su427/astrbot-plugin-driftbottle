# 漂流瓶插件

匿名情绪漂流瓶——私聊投递小纸条，群内捞取/开箱读出，营造情绪接纳的信任空间。

## 使用场景

垃圾话漂流瓶：每人写一封匿名的小纸条（可以是疲惫/脆弱/小委屈/开心事），放进小纸箱/漂流瓶，一周当众对照纸条读出来，营造情绪接纳的信任空间。

## 双瓶海系统

插件维护两套瓶海：
- **大群瓶海**：所有投递的纸条都会进入，`/捞瓶` 从中捞取
- **小组私有瓶海**：只有属于该小组的成员投递的纸条会进入，`/开箱` 和 `/自家鱼塘` 从中操作

投瓶时，纸条会**同时**进入大群瓶海和所属小组的私有瓶海。

## 指令列表

### 私聊指令

| 指令 | 说明 |
|------|------|
| `/投瓶 <内容>` | 匿名投入一张小纸条（最多 500 字），同时进入大群瓶海 + 所属小组瓶海 |
| `/我的瓶子` | 查看自己投入且仍在漂流中的纸条（显示编号、点赞数、所在池子、投入时间） |
| `/收回 <编号>` | 收回自己漂流中的纸条（从所有池子移除，编号为大群序列号） |
| `/设置小组 <组名>` | 手动设置自己所属的小组（如盲盒插件已配置则无需手动） |

### 群聊指令

| 指令 | 说明 |
|------|------|
| `/捞瓶` | 从**大群瓶海**随机捞一张匿名纸条（不会捞到自己投的，不修改状态） |
| `/自家鱼塘` | 根据发送者所属小组，从**小组私有瓶海**随机捞一张纸条（显示投瓶人姓名） |
| `/开箱` | 根据发送者所属小组，一次性展示该小组所有纸条 |
| `/赞 <编号>` | 给指定编号的漂流瓶点赞（每人每瓶只能赞一次，防重复） |
| `/瓶海` | 显示大群瓶海 + 所属小组瓶海的数量统计 |

## 展示格式

**捞瓶（大群，匿名）**：
```
🫧 捞到了一张小纸条：

【第 42 号漂流瓶】
「最近好累啊」
——来自某位同学
```

**自家鱼塘（小组，显示姓名）**：
```
🫧 从【第1组】的鱼塘捞到了一张小纸条：

【第 42 号漂流瓶】
「今天开心」
——来自张三  ❤️ 3
```

**开箱（小组，显示姓名）**：
```
📦 打开了【第1组】的漂流瓶箱，共 3 张小纸条：

【第 42 号漂流瓶】
「最近好累啊」
——来自张三  ❤️ 3

【第 7 号漂流瓶】
「今天开心」
——来自李四

【第 15 号漂流瓶】
「好困」
——来自王五  ❤️ 1
```

## 编号规则

- 编号为**纯数字**，等于瓶子在大群池中的位置序号（从1开始）
- 同一个瓶子在不同池子中展示时使用相同编号
- `/赞 42` 即可点赞第42号漂流瓶

## 小组识别机制（混合方案）

1. **优先**从盲盒插件读取 `member_to_group` 映射（自动同步）
2. **备用**通过 `/设置小组 <组名>` 手动设置，缓存到本地 KV 存储
3. 手动设置的优先级高于盲盒插件的配置

## 匿名性

- `/捞瓶`（大群）保持匿名，不显示投递者信息
- `/自家鱼塘` 和 `/开箱`（小组）显示投递者姓名
- 数据中虽然记录了投递者 ID（用于防自己捞到自己的纸条、判断所属小组），但大群展示时绝不暴露

## 数据存储

- 使用 JSON 文件存储，路径：`data/plugins/astrbot-plugin-driftbottle/bottles.json`
- 数据结构：
  ```json
  {
    "public": [瓶子列表],
    "groups": {
      "第1组": [瓶子列表],
      "第2组": [瓶子列表]
    }
  }
  ```
- 零额外依赖，仅使用 Python 标准库
- 兼容 v2.0.0 的单列表格式，自动迁移到双池结构

## 与盲盒插件的关系

- 漂流瓶是盲盒任务池中的"交流类"任务之一
- 两个插件运行时独立，可单独启停
- 漂流瓶会自动读取盲盒的小组映射数据，无需手动重复配置
- 复用了盲盒插件的 QQ 识别逻辑和数据目录解析方式
